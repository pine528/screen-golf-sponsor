## B. 정의가 없어 화면에서 뺀 지표

| # | 항목 | 상황 | 필요한 것 |
|---|------|------|----------|
| B1 | **SPONPIK INDEX** | 시안 선수카드·퀵프로필에 있으나, 기존 SIE 점수는 브랜드 컨텍스트(업종·목표·예산)가 있어야 계산된다. 컨텍스트 없는 단일 지수는 정의가 없어 목록에서 제외하고 팬온도·최근 성적·시작가로 대체 | 컨텍스트 없는 INDEX 산식 (구성요소·가중치·정규화 기준) |
| B2 | **팬 온도 (선수 프로필용)** | 팬 참여 원장 기반 값은 구현됨. 다만 시안의 "30℃" 수준 초기값·기준 온도 개념이 없어 신규 선수는 0.0℃로 시작 | 기준 온도(baseline) 또는 초기 부여 정책 |
| B3 | **오각형 레이더 5축** | 시안 퀵프로필의 경기력/전염/콘텐츠/브랜드적합도/활동성 — SIE subScores와 축 이름이 다름 | 축 정의와 SIE subScores 매핑표 |

> 원칙: 산출 근거가 없는 수치는 화면에 넣지 않는다 (LEG-06). 위 3건은 정의가 오면 바로 붙인다.

## 처리 방법

1. 새 시안·핸드오프 작업 중 보류가 생기면 이 문서에 **먼저 추가**한다.
2. 남은 화면 작업이 끝나면 A → B → C 순으로 일괄 처리한다.
   - A는 상수 표 수정이라 대부분 한 커밋에 끝난다.
   - B는 정의를 받은 뒤 화면에 붙이는 작업.
   - C는 기능별로 나눠 진행한다.
3. 처리한 항목은 체크하고, DEVLOG에 기록한 뒤 이 문서에서 지운다.
