작업 중 "나중에 한번에" 처리하기로 미뤄둔 것들을 모아둔다.

실제 구현은 남은 화면 작업이 끝난 뒤 일괄로 진행한다.

## B. 정의가 없어 화면에서 뺀 지표

| # | 항목 | 상황 | 필요한 것 |
|---|------|------|----------|
| B1 | **SPONPIK INDEX** | 시안 선수카드·퀵프로필에 있으나, 기존 SIE 점수는 브랜드 컨텍스트(업종·목표·예산)가 있어야 계산된다. 컨텍스트 없는 단일 지수는 정의가 없어 목록에서 제외하고 팬온도·최근 성적·시작가로 대체 | 컨텍스트 없는 INDEX 산식 (구성요소·가중치·정규화 기준) |
| B2 | **팬 온도 (선수 프로필용)** | 팬 참여 원장 기반 값은 구현됨. 다만 시안의 "30℃" 수준 초기값·기준 온도 개념이 없어 신규 선수는 0.0℃로 시작 | 기준 온도(baseline) 또는 초기 부여 정책 |
| B3 | **오각형 레이더 5축** | 시안 퀵프로필의 경기력/전염/콘텐츠/브랜드적합도/활동성 — SIE subScores와 축 이름이 다름 | 축 정의와 SIE subScores 매핑표 |

> 원칙: 산출 근거가 없는 수치는 화면에 넣지 않는다 (LEG-06). 위 3건은 정의가 오면 바로 붙인다.

## C. 미구현 기능 (핸드오프에 정의됨)

### C1. 직접 선택 PICK
- [ ] **후면 도식 이미지** — 좌표가 정면만 실측되어 있어 후면은 '등' 목록으로 대체 중.
      후면 실루엣 이미지 + `SLOT_DISPLAY_COORDS` 후면 좌표 측정 필요
- [ ] **협의형(NEGOTIATED) 흐름** — 상태만 정의, 협의 → 재견적 → 확정 흐름 없음
- [ ] **경매 브릿지** — 경매 슬롯은 상태 표시만. 별도 주문·낙찰 후 합류 미구현 (§7.2)
- [ ] **비로그인 soft PICK** — 3개·7일 로컬 저장 + 로그인 시 서버 draft 병합 (§2.3 · §7.4)
- [ ] **revision 재승인** — 승인 후 조건 변경 시 revision 생성·영향 선수만 재승인 (§7.3)
- [ ] **대체 항목 자동 교체** — 현재는 대체안 링크만 제공, 클릭 시 항목 교체까지 (§6.3)
- [ ] **DATE_OVERLAP / CATEGORY_EXCLUSIVE / EVENT_RULE 충돌 검사** — 코드·문구는 준비, 실제 판정 로직 없음
- [ ] **데이터 최신성 차단** — `freshnessStatus` STALE 시 결제 차단 (§11.3 · §12.3)

## 처리 방법

1. 새 시안·핸드오프 작업 중 보류가 생기면 이 문서에 **먼저 추가**한다.
2. 남은 화면 작업이 끝나면 A → B → C 순으로 일괄 처리한다.
   - A는 상수 표 수정이라 대부분 한 커밋에 끝난다.
   - B는 정의를 받은 뒤 화면에 붙이는 작업.
   - C는 기능별로 나눠 진행한다.
3. 처리한 항목은 체크하고, DEVLOG에 기록한 뒤 이 문서에서 지운다.
