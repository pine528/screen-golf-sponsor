# SponsorGolf 시연 가이드

> **시연일**: 2026년 1월 21일
> **플랫폼**: 브랜드-선수 스폰서십 마켓플레이스 + 팬 참여 시스템

---

## 1. 플랫폼 개요 (1분 설명용)

**SponsorGolf**는 프로 골퍼와 브랜드를 연결하는 **스폰서십 마켓플레이스**입니다.

### 핵심 가치
- **선수**: 스폰서십 슬롯을 등록하고 브랜드로부터 후원을 받음
- **브랜드**: 경매/즉시구매로 선수 스폰서십을 확보하고 마케팅 진행
- **팬**: 투표 참여로 포인트를 얻고, 포인트샵에서 상품 교환

### 수익 모델
- 스폰서십 거래 성사 시 **10% 플랫폼 수수료**
- 팬 투표 참여비 일부 플랫폼 귀속

---

## 2. 사용자 역할 (4가지)

| 역할 | 설명 | 주요 활동 |
|------|------|----------|
| **ADMIN** | 운영자 | 회원 승인, KYC 심사, 분쟁 중재, 정산 관리 |
| **BRAND** | 브랜드 | 선수 검색, 입찰/구매, 계약 체결, 캠페인 운영 |
| **ATHLETE** | 선수 | 슬롯 등록, 오퍼 검토, 계약 서명, 정산 수령 |
| **FAN** | 팬 | 투표 참여, 포인트 획득, 포인트샵 이용 |

|------|-----|------|
| 대시보드 | `/dashboard` | 브랜드 활동 요약 |
| 인벤토리 | `/inventory` | 구매 가능한 선수 슬롯 탐색 |

| 계약 관리 | `/contracts` | 체결된 계약 목록 |
| 지갑 | `/brand/wallet` | 충전금 관리, 결제 내역 |
| 캠페인 | `/campaigns` | 마케팅 캠페인 생성/관리 |
| 후원 투표 | `/brand/sponsored-votes` | 브랜드 후원 팬 투표 |
| ROI 리포트 | `/brand/reports/roi` | 스폰서십 투자 대비 효과 분석 |

#### 시연 추천 흐름 (선수 스폰서십 구매)
1. **인벤토리** `/inventory` → 선수 슬롯 목록 확인
2. 선수 카드 클릭 → **선수 상세** `/athletes/:id`
3. "즉시 구매" 또는 "입찰하기" 클릭
4. **경매** `/auctions` → 입찰한 경매 확인
5. 낙찰 후 **계약 관리** `/contracts` → 계약서 확인
6. **지갑** `/brand/wallet` → 결제 진행

#### 핵심 기능 시연
- **즉시 구매**: 선수가 설정한 가격으로 바로 구매
- **경매 입찰**: 최고가 경쟁 입찰
- **에스크로 결제**: 계약 완료 전까지 금액 보호

### 3.4 ATHLETE (선수) 시연

**로그인 후 URL**: `/dashboard`

#### 주요 메뉴 설명

| 메뉴 | URL | 설명 |
|------|-----|------|

| 슬롯 관리 | `/my-slots` | 스폰서십 슬롯 등록/관리 |
| 계약/오퍼 | `/contracts` | 받은 오퍼 및 계약 목록 |
| 서명 대기 | `/athlete/pending-signatures` | 서명이 필요한 계약 |
| 정산 | `/settlements` | 정산 내역 확인 |
| 출금 관리 | `/athlete/withdrawals` | 수익금 출금 신청 |
| 투표 | `/votes` | 관련 팬 투표 현황 |
| 프로필 | `/profile` | 선수 프로필 관리 |

#### 시연 추천 흐름 (슬롯 등록 → 계약)
1. **슬롯 관리** `/my-slots` → "새 슬롯 등록" 클릭
2. 슬롯 유형 선택 (모자, 의류, 장비 등)
3. 가격 설정 (즉시구매가, 경매 시작가)
4. **계약/오퍼** `/contracts` → 받은 오퍼 확인
5. 오퍼 수락 → **서명 대기** → 전자 서명
6. 계약 완료 후 **정산** → 정산 예정 금액 확인

#### 슬롯 유형 예시
- **모자 로고**: 모자에 브랜드 로고 부착
- **상의 로고**: 셔츠/재킷에 로고
- **장비 사용**: 특정 브랜드 장비 사용
- **SNS 홍보**: 소셜미디어 포스팅

### 3.5 FAN (팬) 시연

**로그인 후 URL**: `/fan`

#### 주요 메뉴 설명

| 메뉴 | URL | 설명 |
|------|-----|------|
| 홈 | `/fan` | 팬 전용 홈 (추천 투표, 인기 선수) |
| 투표 | `/votes` | 진행 중인 투표 목록 |
| 내 투표 | `/fan-votes/my` | 참여한 투표 내역 |
| 내 뱃지 | `/fan/badges` | 획득한 뱃지 컬렉션 |
| 내 포인트 | `/points` | 포인트 잔액 및 내역 |
| 포인트샵 | `/shop` | 포인트로 상품 교환 |
| 교환내역 | `/orders` | 포인트샵 주문 내역 |
| 랭킹 | `/ranking` | 팬 활동 랭킹 |
| 즐겨찾기 | `/favorites` | 관심 선수 목록 |
| 브랜드 등록 | `/brand-register` | 브랜드 계정 전환 신청 |

#### 시연 추천 흐름 (투표 → 포인트 획득 → 상품 교환)
1. **투표** `/votes` → 진행 중인 투표 확인
2. 투표 카드 클릭 → 상세 페이지
3. 예측 선택 후 포인트 베팅
4. **내 투표** `/fan-votes/my` → 참여 내역 확인
5. 투표 종료 후 정답 맞추면 포인트 획득!
6. **포인트샵** `/shop` → 상품 둘러보기
7. 상품 선택 → 포인트로 교환
8. **교환내역** `/orders` → 주문 상태 확인

#### 투표 시스템 설명
- 팬이 포인트를 걸고 예측 투표
- 정답자 중 랜덤 당첨자에게 풀 분배
- 오답 또는 미당첨 시 포인트 소진

## 8. 자주 묻는 질문 (시연 중 예상 질문)

**Q: 수수료는 어떻게 되나요?**
> A: 스폰서십 거래 성사 시 거래 금액의 10%를 플랫폼 수수료로 수취합니다.

**Q: 결제는 어떻게 이루어지나요?**
> A: 에스크로 방식입니다. 브랜드가 결제하면 플랫폼에서 보관하고, 계약 완료 후 선수에게 정산됩니다.

**Q: 팬은 어떻게 포인트를 얻나요?**
> A: 투표 참여 후 정답을 맞추면 풀에서 분배받습니다. 관리자 지급도 가능합니다.

**Q: 선수 인증은 어떻게 하나요?**
> A: 선수가 본인인증 서류를 제출하면 관리자가 KYC 심사 후 승인합니다.

**Q: 브랜드 등록은 어떻게 하나요?**
> A: 팬 계정으로 가입 후, "브랜드 등록" 메뉴에서 사업자 정보를 제출하면 관리자 승인 후 전환됩니다.
